# Use one SSH stream protocol with a standalone node collector

Each Target Node uses one OpenSSH process: the Collection Workstation sends one readable self-contained `remote_collector.py` to the fixed remote `python3 -` command on standard input, receives only the gzip Node Evidence Archive on standard output, and captures diagnostics on standard error. Avoiding per-Probe sessions, `scp`, zipapps, base64 wrappers, and generated source keeps the ephemeral no-install protocol small, auditable, and compatible with the Python 3.10 production floor; a configured Ceph source performs its cluster Probes in that same session.
